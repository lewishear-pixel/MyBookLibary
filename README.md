# My Book Library

A bookshelf-style book tracker with:

- ISBN barcode scanning
- Google Books + Open Library lookup
- Already Read / Currently Reading / Want to Read shelves
- Search
- Book detail cards
- Move books between shelves
- Remove books
- Local browser backup
- Optional Supabase accounts and cloud library sync
- Responsive phone layout

See `SETUP.md` for Supabase account/database setup.
